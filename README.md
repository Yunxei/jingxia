<summary>安装说明</summary>

<a id="installation"></a>

```text
下载压缩包后解压文件夹，将文件夹放入：
X:\My Documents\ArcheRage\Addon

注意：
X 不是固定盘符，它代表你电脑上“文档”文件夹所在的盘。

不同系统：
• Win10/Win11 中文：文档
• Win7 中文：我的文档
• 英文系统：Documents / My Documents

请不要直接复制 X。
```
