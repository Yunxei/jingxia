插件安装方法：
下载压缩包后解压文件夹，将文件夹放入到“X:\My Documents\ArcheRage\Addon”下

路径里的X不是固定盘符，它代表你电脑上“文档”文件夹所在的盘。
有的人是 C 盘，有的人是 D 盘、E 盘，所以不要照抄 X。
“我的文档”在不同系统里叫法不同：
• Win10/Win11 中文：文档
• Win7 中文：我的文档
• 英文系统：Documents / My Documents
